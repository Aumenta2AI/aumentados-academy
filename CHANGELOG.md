# Historial de cambios

## 0.1.0 — Base inicial

- Academia con roles de administrador, editor y estudiante.
- Módulos y clases con vistas de tarjetas/lista y bloques ordenables.
- Grabación de pantalla y cámara flotante, anotaciones y fondos.
- Seguimiento individual, comentarios y exportación de avances.
- Caché ETag, índices SQLite y protección de operaciones concurrentes.
- 18 pruebas de integración y pruebas de navegador con dispositivos simulados.
- Flujo de GitHub Actions para pruebas del servidor y sintaxis JavaScript.

Esta versión identifica el código existente. No implica que el servidor completo esté publicado en Vercel.
